## Next Steps

**All slots start locked (level 0) — no customization is enabled yet.** To unlock:

```bash
npx invariance-unlock colors          # allow color changes on all slots
npx invariance-unlock fonts           # allow font changes
npx invariance-unlock page / --level 1  # set F1 (style) on the home page
npx invariance-unlock all             # unlock everything
```

Or edit `invariance.config.yaml` directly — change `level: 0` to `level: 1` (F1 style) or higher on any page.

**Set your API key** in `.env.local`:
```
NEXT_PUBLIC_ANTHROPIC_DEV_API_KEY=sk-ant-...
```

**Start the dev server** and open the customization panel (bottom-right ✦ button).
